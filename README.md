# 众生长地｜公开资源仓库

本仓库只存放「ᛇ：众生长地」角色卡中**明确允许公开、且确实需要运行时外连的大型自制资源主体**。

本仓库与私人主仓库分工：

- 本仓库：保存大型正则界面与大型酒馆助手脚本的资源主体。
- 私人主仓库：保存角色卡配置、载入框架、资源锁定清单与构建规则。
- 角色卡：在运行时按固定 commit SHA 请求本仓库的公开资源。

## 目录结构

```text
zhongsheng-changdi-assets/
├── regex/
│   └── README.md
├── scripts/
│   └── README.md
└── README.md
```

每项正式资源使用独立的 kebab-case 目录。\n\n\`tests/\` 只存放隔离的技术验证样本，不属于正式资源目录，不进入角色卡资源锁定清单，也不代表角色卡功能规划。具体文件结构见对应目录说明。

## 固定版本引用

正式角色卡不得引用 `main`、分支名、浮动 tag 或 `@latest`。

资源引用使用不可变 commit SHA：

```text
https://raw.githubusercontent.com/yin-shi-luo142cm/zhongsheng-changdi-assets/<40位commit-sha>/<资源路径>
```

SHA 与资源路径由私人主仓库的 `resources.lock.json` 统一锁定。不要在本仓库内部维护指向自身当前 commit 的版本号，以免产生自我引用。

## 公开内容边界

- 只提交已经确认可以公开的资源。
- 不提交私人世界观草稿、角色卡完整 JSON、用户资料、访问令牌、密钥或其他凭证。
- 不复制或镜像第三方共享库；MVU beta 继续使用其原有第三方稳定资源链接。
- 不在没有确认授权方式前添加许可证声明。当前仓库未声明开放源代码许可证。

## 变更原则

- 已发布版本由 commit SHA 固定，后续修改产生新版本，不覆盖旧版本引用。
- 正式发布前，在目标 SillyTavern 环境验证 URL、MIME、CORS、缓存与载入失败处理。
- 资源路径应稳定、语义清楚；避免只用数字或临时名称。
